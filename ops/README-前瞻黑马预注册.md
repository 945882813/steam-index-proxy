# Steam 独立游戏雷达：前瞻性黑马预注册（PF-2026-10-V1）

本模块只扩展现有 GitHub + Google Sheets 架构。**不会修改「黑马预测基线」和「黑马后验评估」历史记录**，也不会新增任何定时任务。新模块由 `prospective_forecast.py` 提供显式的 `audit`、`register`、`evaluate` 命令。

## Sheet 结构与保护边界

- `黑马前瞻预测`：只允许追加新锁定预测。包含锁定时间、AppID、游戏发行阶段、研究假设、证据链接、35/25/25/15 分项评分、固定规则版本和规则 JSON 快照、真实采集时间的 CCU/评论基线、来源、干扰因素审查计划、记录 SHA-256 指纹。
- `黑马前瞻后验`：可刷新，分别存 D7 和 D30 的证据状态、增长和评论差分、阈值候选判断、归因审查状态以及初始记录指纹。
- **规则快照与锁定内容不可事后调参**；下一版本必须使用新的规则版本，并仅用于未来锁定的新预测。指纹能够检测普通误改，**不能防止拥有 Sheet 编辑权限的人同步修改值和指纹**。为获得跨平台证据，请保留具体 GitHub 运行记录与日志中的锁定 ID/指纹。
- 前瞻登记同一 AppID 在同一北京时间自然日最多一条；无真实基线的待发售预测可以登记，但其后验保持 `BASELINE_MISSING`，**不得事后拿发售后采样回填锁定时基线**。Demo、未发行和成熟参照均排除新游黑马候选判断。

## 固定 V1 研究筛查门槛（非统计显著性与预测成功定义）

| 项目 | 预注册标准 |
|---|---|
| 评分权重 | 玩法创新 35%；黑马潜力 25%；玩家趋势 25%；商业热度 15% |
| CCU 基线 | 锁定前 12 小时内、VERIFIED 或有效 FRESH_FALLBACK；Steam Index 与 Steam Official 不能跨源比较 |
| 评论基线 | 锁定前 12 小时内，Steam 官方 `all`、严格统一 filter 的真实累计评论 |
| 最低分母 | CCU ≥20，累计评论 ≥30；低于门槛只保留 `LOW_BASE` |
| D7 观察 | 基线 +7 日；CCU ±3.25 小时、评论 ±12 小时；净评论 ≥50 且 CCU 同源增长 ≥25% |
| D30 观察 | 基线 +30 日；同样窗口与过滤规则；净评论 ≥200 且 CCU 同源增长 ≥40% |
| 观察达标 | 仅 `SIGNAL_CANDIDATE_REQUIRES_ATTRIBUTION`，**不表示黑马成立、不直接统计命中率** |
| 干扰解释 | 促销/折扣、节日、首发及更新、主播/媒体曝光、Demo/正式版映射、独立品类等必须人工审核；未复核保留 `PENDING_MANUAL_ATTRIBUTION` |

这些阈值属于明确写入锁定记录的**首版研究筛查假设**，尚未在足量样本上检验。不得把 50 条评论或 25% 增长称为统计意义上的黑马成功阈值。

## 操作

环境必须通过 GitHub Secrets 或相应的安全凭据管理提供 `GOOGLE_SERVICE_ACCOUNT_JSON`、`GOOGLE_SHEET_ID`。不要在聊天、日志或 Sheet 中输出密钥。

```sh
python prospective_forecast.py audit
# 对经人工复核的本地 JSON 做显式登记；不会自动挑选 Top10
python prospective_forecast.py register --draft-file reviewed_forecast.json
# 仅从现有 Sheet 可信样本重算后验；不会抓取 Steam，也不会修改锁定预测
python prospective_forecast.py evaluate
```

登记输入为一个 JSON 对象，字段为：`AppID`、`游戏名称`、`观察阶段`（已发行/待发售/Demo/成熟参照）、`研究假设`、同 AppID 的 Steam 官方 `证据链接`、`玩法创新分`、`黑马潜力分`、`玩家趋势分`、`商业热度分` 和 `活动干扰核验计划`。四项评分为 0–100 的研究优先级分，非胜率。锁定时间以运行机器的 UTC 时钟产生，不接受 JSON 指定或回填锁定时间。

`audit` 只核实工作表表头、记录指纹、政策版本和重复预测键；`evaluate` 只刷新派生后验。首次部署没有真实新预测时，只允许空队列验收，不允许插入测试用虚构预测。

## 当前未实施

- 没有连接到现有每天凌晨采集/09:30 报告自动链路；
- 没有自动发布黑马成功结论或预测命中率；
- 没有验证 Apps Script 独立平台触发器的实际安装及运行；
- 没有自动进行促销/节日/曝光干扰的因果归因。

预注册阈值的研究价值需要随**未来真实、不可回改、足量**的队列和对照组累积才能检验。
